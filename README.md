# startpage query as title
Firefox extension to change the tab title on Startpage to show your search query.

The default search method for startpage is POST, which doesn't save your search query in the title bar, you can enable it by setting GET method as default in the settings page. Doing this saves a cookie on your browser to remember your settings, you can also use a special URL given by startpage if you don't want any cookie.
This extension is only useful if you don't want any cookies saved by startpage on your machine or any special URL to use.
You will get your search query in the title even when using the POST method.
